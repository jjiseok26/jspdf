# JSPDF 0.1

Windows 설치형(Electron) PDF 편집기. PDF 열기·주석·본문 수정·병합·변환·역변환·이미지 저장·워터마크·프레젠테이션·전자인장을 지원합니다.

## 버전

현재 버전: **0.1.0** (`package.json`, `VERSION`, Git 태그 `v0.1.0`)

변경 이력은 [CHANGELOG.md](CHANGELOG.md)를 참고하세요.

## 실행 / 빌드

```bash
npm install
npm start                # 개발 실행
npm run smoke            # 렌더링·PDF 기능 자동 점검 (스크린샷 포함)
npm run dist             # dist/ 에 Windows NSIS 설치파일 생성
```

설치파일은 `dist/JSPDF Setup 0.1.0.exe` 로 생성되며, 설치 경로 선택과 바탕화면 바로가기를 지원합니다.

## 기능

| 기능 | 설명 |
| --- | --- |
| PDF 열기 / 확대·축소 | pdf.js 기반 연속 페이지 뷰어 (40% ~ 300%) |
| 펜 / 형광펜 / 메모 주석 | 자유 곡선, 반투명 하이라이트, 메모 박스 |
| 본문 수정 | 기존 내용을 배경색으로 덮고 새 텍스트(한글 지원) 삽입 |
| 전자인장 | 이름으로 원형 인장을 자동 생성하거나 인장 이미지 파일 사용 |
| PDF 병합 | 여러 PDF를 선택 순서대로 하나로 합치기 |
| 워터마크 | 문구·투명도·기울기를 지정해 전 페이지에 적용 |
| 이미지로 저장 | 전 페이지를 2배 해상도 PNG로 폴더에 저장 (주석 포함) |
| PDF 변환 | 이미지(PNG/JPG) → PDF, 텍스트(TXT/MD) → PDF |
| PDF 역변환 | 문서 텍스트를 TXT 또는 HTML로 추출 |
| 프레젠테이션 | 전체화면 페이지 넘김 (← → / Space / Esc) |
| 페이지 순서 변경 | 좌측 썸네일을 끌어다 놓아 순서 변경, 저장·이미지 저장·프레젠테이션에 그대로 반영 |
| 드래그 앤 드롭 | PDF 파일을 창에 놓으면 바로 열림 |
| 연결 프로그램 | 설치 후 PDF 우클릭 → 연결 프로그램에 JSPDF 표시 |
| 텍스트 선택/복사 | 선택 도구에서 글자를 드래그해 선택, `Ctrl+C`로 복사 |
| OCR | 스캔 PDF는 열 때 자동 인식, 수동 실행은 **OCR 실행** 버튼 |

## 화면 구성

- **상단 리본**: 파일/확대·프레젠테이션 행 + 편집 도구·인장·문서 작업 행
- **좌측 패널**: 페이지 썸네일. 클릭하면 해당 페이지로 이동하고, 끌어다 놓으면 순서가 바뀝니다(라벨에 원본 쪽 번호 표시).

## 조작 방법

- 리본에서 도구를 고르고 페이지를 클릭·드래그하면 주석이 추가됩니다.
- `선택/이동` 도구로 주석을 끌어 옮기고, `Delete` 로 삭제, 텍스트 주석은 더블클릭으로 수정합니다.
- `저장` 을 누르면 모든 주석이 PDF에 합성(flatten)되어 새 파일로 저장됩니다.
- **선택/이동** 도구일 때 본문 글자를 드래그해 선택하고 `Ctrl+C`로 복사할 수 있습니다.
- 텍스트가 없는 스캔 PDF는 열 때 OCR이 자동 실행됩니다(최초 1회 한·영 언어 데이터 다운로드 필요).

## 업데이트(재설치) 방법

기능이 추가된 버전을 쓰려면 `dist/JSPDF Setup 0.1.0.exe` 로 **다시 설치**하면 됩니다.

## 구조

```
src/main/main.js       Electron 메인 프로세스, 파일 다이얼로그 IPC
src/main/preload.js    contextBridge 로 노출하는 안전한 파일 API
src/renderer/app.js    UI 상태, 뷰어 렌더, 도구 상호작용, 액션
src/renderer/annots.js 주석 데이터 모델과 캔버스 렌더 (정규 좌표 0~1)
src/renderer/pdfops.js pdf-lib 기반 합성·병합·워터마크·변환
```

## 0.1의 제한 사항

- 본문 수정은 원본 텍스트 스트림을 직접 고치는 방식이 아니라, 덮어쓰기 + 새 텍스트 삽입 방식입니다.
- 주석은 저장 시 페이지 이미지로 합성되므로 저장 후에는 개별 주석을 다시 편집할 수 없습니다.
- PDF 역변환은 텍스트 기준이며 표·이미지 레이아웃은 보존되지 않습니다.
